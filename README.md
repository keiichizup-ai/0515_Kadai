🚀 じゃんけんWebアプリ：制作要件仕様書
1. 開発概要
ユーザーが「サザエさんの最後の一勝負」のようなワクワク感を楽しめる、ブラウザ完結型のじゃん
けんゲームを制作する。
2. 技術スタック・構成
● ファイル構成: 1. index.html (構造)
2. style.css (デザイン)
3. script.js (ロジック)
● 制約: 外部ライブラリは使用せず、Vanilla JSと標準CSSのみで構成する。VS Codeでの編集を
前提としたクリーンなコード。
3. 機能要件
● ゲームの流れ:
1. 待機画面: 「勝負する！」ボタンを表示。
2. 選択: ユーザーが「グー・チョキ・パー」のアイコン/ボタンを選択。
3. 演出: コンピューターの手が決定するまで、数秒間のアニメーション（「ジャン・ケン・ポ
ン！」のリズム）を挟む。
4. 判定: 勝敗（勝ち・負け・あいこ）を判定し、結果を画面に大きく表示。
5. リセット: 「もう一度遊ぶ」ボタンで初期状態に戻る。
● ロジック: * コンピューターの手は Math.random() を用いて等確率で選出。
○ 勝敗判定アルゴリズムの実装。
4. UI/UX デザイン指針 (Vibe)
● 「サザエさん」体験の再現: * 単なるテキスト表示ではなく、キャラクターや手のイラスト（絵文字
でも可）が動く楽しさを演出。
○ 「さあ、今週の運勢は？」といった、親しみやすいメッセージを表示。
● 視覚効果: * ボタンホバー時のインタラクション（拡大、色の変化）。
○ 勝敗が決まった際、画面全体が「おめでとう！」や「残念！」といった色（金や青など）に変
化する演出。
○ 中央に大きな「手の出し合い」を行うメインステージを配置。
● レスポンシブ: スマホでもPCでも操作しやすい中央寄せのレイアウト。
5. 各ファイルの役割詳細
index.html
● ゲームのタイトル、メイン画像/絵文字表示エリア、操作用ボタン（グー・チョキ・パー）を配置。
● スコアボード（連勝記録など）があれば尚可。
style.css
● モダンでポップなカラーパレット（例：背景は温かみのある黄色系）。
● アニメーション（@keyframes）を使用して、じゃんけん待機中の「揺れ」を表現。
● カード風のデザインや角丸を多用した親しみやすい外観。
script.js
● DOM操作による画面遷移の制御。
● setTimeout を活用した「ポン！」のタイミング演出。
● 勝敗判定ロジック。
